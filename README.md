# Python Mini Projects & Algorithm Lab

A collection of standalone Python programs exploring data structures, classical algorithms, interactive CLI games, and utility automation.

## Project Catalog

### Algorithms & Data Structures
| Script | Concept / Description |
|---|---|
| `binary_search_tree.py` | Binary Search Tree (BST) implementation with insertion, search, and traversal |
| `merge_sort_algorithm.py` | Divide-and-conquer merge sort implementation |
| `shortest_path_algorithm.py` | Graph traversal and shortest path computation using Dijkstra's algorithm |
| `sudoku_solver.py` | Backtracking algorithm to solve 9x9 Sudoku puzzles |
| `tower_of_hanoi.py` | Recursive solution to the classical Tower of Hanoi puzzle |

### Utilities & Tools
| Script | Concept / Description |
|---|---|
| `ai_agent.py` | Rule-based agent simulation |
| `digital_book_collection.py` | Interactive terminal book catalog with search and management features |
| `text_transformation_toolkit.py` | Text parsing, case transformations, and manipulation toolkit |
| `time_calculator.py` | Duration addition and 12-hour/24-hour cycle arithmetic |
| `sequence_compression.py` | Lossless run-length compression and decompression algorithms |
| `unique_streak_finder.py` | Sequence analysis tool to detect unique character and value streaks |

### Terminal Games
| Script | Concept / Description |
|---|---|
| `rock_paper_scissors.py` | Command-line Rock-Paper-Scissors against computer AI |
| `guess_a_number.py` | Number guessing game featuring dynamic hints and attempt tracking |
| `random_sentence_generator.py` | Grammar-pattern randomized sentence generator |

## Getting Started

### Prerequisites
- Python 3.8+ installed (uses Python Standard Library only).

### Running Scripts
Execute any script directly with Python:
```bash
# Example: Run the Sudoku Solver
python sudoku_solver.py

# Example: Run the Digital Book Collection
python digital_book_collection.py
```
